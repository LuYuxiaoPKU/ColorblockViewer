## 一、为什么要重写

现有 Wiki（10 页 672 行）的强项与短板：

| 维度 | 现状 | 问题 |
|---|---|---|
| 命令/表达式/NBT 语义 | 与预览引擎逐字对齐，1161 测试锁定 | **强项，保留**；但缺少版本差异维度（三代指令树） |
| 历史与命名 | overview 一张 4 行表 | **最薄弱**：ColorBlock→ExParticle 沿革、MCBBS 原帖、作者、协议、版本史全部缺失 |
| 生态引用 | faq 提到 viewer.dbi.top / 生成器站一句话 | 无出处、无链接、无贡献者致谢；「引用他人成果需注明来源」未落实 |
| 粒子类型 | 26.2 表为主，1.21.11 一行带过 | 基岩版/网易版完全没提（社区生态的一半） |
| 示例 | 5 个引擎实测 + 2 模板 | 社区 17 个现成案例（OCEAN 站）一个都没收录 |
| 表达式 | 语法速查 + 变量表 | 缓动函数库、分段表达式、浮点陷阱、颜色管线只有零星提及 |

结论：语义层（引擎对齐部分）**不要推倒**，重写重心是 **补历史、补生态、
补来源、补版本维度**。

## 二、重写原则（协作对齐用）

1. **严谨分层**：每个事实标注置信级——
   - **[源码级]** 模组/游戏字节码或源码直接核对（预览引擎测试锁定）
   - **[官方级]** 模组作者发布帖/文档（MCBBS 原帖、mcmod post/4889、ExParticle README）
   - **[社区级]** B 站视频/专栏/论坛（OCR 或存档），标注「待验证」如未经引擎实测
2. **引用格式**（待会话②对齐，初步方案）：
   - 视频引用：`（B 站 @UP主《标题》 BV号，OCR 存档见 Bili-Video-Learn 知识库）`
   - 文档引用：`（翊尘呀《ColorBlock 教程——更好的粒子》cv21908911，1.16.5 口径）`
   - 站点引用：`（OCEAN 生成器站 mc.ecyft.top，镜像 tools.pj568.top）`
   - 每页文末统一「来源与致谢」节
3. **内容边界**：Wiki = 权威语义 + 沿革 + 入口链接；社区笔记细节（逐视频拆解、
   网易版差异全集、UP 群像）**留在 Bili-Video-Learn**，Wiki 只做「入口 + 一句话」
   并链接过去（或链接到 mcmod 原帖等公开来源，知识库本身是私库则不直链）。
4. **不改 1:1 语义结论**：命令树、报错文案、NBT 校验等源码级结论原样保留，
   重写不引入未经验证的新语义。

## 五、会话②裁决（2026-10-14 回复，全部采纳，已定稿）

1. **引用格式最小字段集**：视频=BV号+UP主+标题；专栏/文档=作者+标题+平台+cv号/post号；站点=站名+URL。**访问日期只加在内容可能随时间变化的引用上**（在线站点、会更新的教程帖）；BV 视频等静态定稿物不加。
2. **Bili-Video-Learn 知识库**：非 git 仓库、无远端、纯本地私库 → **Wiki 不得直链**。只链公开来源（B站 URL/mcmod/GitHub/Modrinth）；需提存档时脚注一句话（「存档于 Bili-Video-Learn 知识库，含 OCR/ASR 原始数据」），不写本地路径。
3. **网易版/基岩版**：进 Wiki 正文，**一句话+外链，不展开**。差异全集（176 种名录等）留知识库。04-particles 一句话 + BV12qRVY4E4p（1maginer）/ BV1N4421D72C（莱德西多）外链。
4. **OCEAN 17 案例首批 6 个**（标准=引擎可验证+作者明确+六种命令面各一例）：正方体（Junior_Mo，conditional）/ 菊型球（故知，rgbapolarparameter）/ 桃心（OCEAN，经典参数方程）/ 旋转的球体（OCEAN，矩阵+RGB 复合）/ 粒子缠绕（OCEAN，normal+旋转）/ 锐角星型（Junior_Mo，参数方程+速度表达式）。其余 11 个进 05-examples 折叠清单。
5. **三代指令树对照表放 01-commands 正文**（日常要查，放 history=埋葬）；08-history 只放沿革叙事，不做表格重复。
6. **贡献者分层致谢**：开发（Junior_Mo/Is_GK/hackerm大神）+ 工具（OCEAN/吴先生）+ 文档（翊尘呀）进 08-history 正文各一行+链接；基岩名录 UP 与教学 UP 群像（20+ 人）=一句话汇总+外链；知识库全图谱作底稿。
