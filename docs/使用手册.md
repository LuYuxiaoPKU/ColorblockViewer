# ColorBlockViewer 使用手册

> 面向第一次使用的玩家。想了解技术原理、1:1 移植细节、性能优化，请看
> [技术路线综述](技术路线.md)；本手册只讲**怎么用**。

## 一、这是什么

一个网页版的 Minecraft 粒子效果预览工具：**粘贴一条粒子命令 → 立刻看到
效果 → 满意后把命令复制回游戏**。支持模组的 `/particleex` 命令和原版
`/particle` 命令，效果与游戏内一致（按模组源码 1:1 复刻）。

打开方式：
- 在线版：https://luyuxiaopku.github.io/ColorblockViewer/
- 本地版：见文末「开发者」一节（适合想改源码的人）

## 二、认识界面

页面分两栏：

```
┌─────────────────────┬──────────────────────────┐
│ 左侧：命令面板       │  右侧：画布（粒子舞台）    │
│ · 标题 + ▶ 播放按钮  │  · 左上角：播放控制条      │
│ · 📚 模板库 / 一键清空 │  · 左下角：状态（tick/粒子数）│
│ · 命令输入框（大文本框）│                          │
│ · 格式检查提示        │                          │
│ · ▸ 设置（折叠）      │                          │
└─────────────────────┴──────────────────────────┘
```

- **tick**：游戏的最小时间单位，1 秒 = 20 tick。看到「tick 100」就是
  第 100 个游戏刻。
- 粒子数很大时（比如 100 万）网页会变慢，这是正常的——见「常见问题」。

## 三、第一次上手（推荐流程）

**方法 A：模板库（不会写命令也能玩）**

1. 点左侧「📚 模板库」
2. 面板里选一个特效（涟漪波面 / 圆周环），点「载入并执行」
3. 画布上立刻出现效果，左侧命令区自动填好对应命令
4. 点「📋 复制命令」就能把命令带进游戏

**方法 B：粘贴自己的命令**

1. 在输入框里粘贴命令（一行一条）
2. 点「▶ 播放」——重置并从头播放
3. 想追加（不清空已有粒子）：点「加入播放器」

## 四、命令怎么写

### 4.1 模组命令：`/particleex`

通用结构（以 `normal` 为例）：

```
particleex normal <粒子名> <位置x y z> <颜色r g b a> <速度vx vy vz> <范围> <数量> [年龄] [速度表达式] [间隔] [组]
```

一个真实例子——在 (0, 64, 0) 生成 5 个红色火焰，向上飞：

```
particleex normal minecraft:flame 0 64 0 1 1 1 1 0 0 1 0 0 0 5
```

- `<位置>`：三个数字（x y z），也可以写 `~` 表示「玩家位置」
- `<颜色>`：四个数字 r 红 / g 绿 / b 蓝 / a 透明度（0–1，1 = 完全不透明）
- `<数量>`：生成几个粒子
- `<范围>`：粒子在多大范围内随机散布

**位置/颜色随时间变化**（这是模组的招牌功能）：用 `parameter` 系列命令，
把「位置表达式」写成公式，粒子会随时间逐 tick 变化。例如水平环形火焰：

```
particleex parameter minecraft:flame 0 64 0 1 1 1 1 0 0 0 0 6.2832 'x,y,z=4*cos(t),3*sin(t),0' 0.1
```

- `x,y,z=` 是**位置表达式**：x = 4·cos(t)、z = 3·sin(t)，`t` 是当前
  游戏刻——粒子会沿着半径 4×3 的椭圆转圈
- 数字 0.1 是「步长」：`t` 每 tick 增加 0.1
- 表达式用单引号包住（含括号和逗号时游戏里必须这样写；预览会自动帮你
  补上，复制回游戏可直接用）

其他子命令：`conditional`（满足条件才生成）、`rgbaparameter` 系列
（颜色随时间变化）、`group remove/change`（批量修改一组粒子）、
`clearparticle`（清空）。每种命令的完整参数说明，粘贴后出错时页面会
提示「用法：particleex …」，照着填即可。

### 4.2 原版命令：`/particle`

```
particle <粒子名> [x y z] [dx dy dz] [速度] [数量] [normal]
```

例子——在 (0, 100, 0) 喷 50 个灵魂火焰：

```
particle minecraft:soul_fire_flame 0 100 0 0.5 0.5 0.5 0.05 50
```

- `[dx dy dz]`：散布范围（随机偏移的范围）
- `[速度]`：粒子初速
- `[数量]`：粒子个数（写 0 = 精确单个粒子）
- 粒子名可用 `type{...}` 复杂写法，比如给 dust 自定义颜色（花括号紧跟
  粒子名、中间不空格）：
  `particle minecraft:dust{color:[1,0.3,0.2],scale:1} 0 64 0 0 0 0 1 1`
- 预览不支持 `force`/`viewers` 两个尾参数（会明确报错提示，与游戏报错一致）

### 4.3 表达式小抄（写给想深入的人）

表达式支持：`+ - * / %`、括号、变量赋值（`a=2;`）、常用函数
（`sin cos sqrt abs exp log pow`）、矩阵。`t` 表示当前游戏刻，是时间
变量；分号分隔多条语句，最后的结果生效。写错会得到和游戏里一模一样的
报错文案，照着提示改即可。

## 五、播放与回看

画布左上角控制条：

| 控件 | 作用 |
|---|---|
| ▶ 播放 / ⏸ 暂停 | 播放或暂停；停在最后一帧时再点 = 从头重跑 |
| ◀ ▶ | 上一帧 / 下一帧（一帧 = 一个游戏刻） |
| 进度条 | 拖动回看播放历史（粒子寿命结束前的每一刻都能拖回去看） |
| ↺ 重置 | 重置并重新执行命令 |
| 0.125×–8× | 倍速（0.5× = 慢放，2× = 快进） |

小知识：粒子寿命全部结束时播放**自动停止并停在最后一帧**，画面保留，
此时可以拖进度条回看整个生命周期。

## 六、设置面板（左侧「▸ 设置」）

| 设置 | 说明 |
|---|---|
| 玩家位置（x y z） | `~` 符号的基准点（默认 0 0 0） |
| 默认寿命 | 粒子默认存活多少 tick（近似值：不同粒子类型实际寿命不同） |
| 粒子上限 | 同时存在的粒子数量上限（默认 100 万）。**卡顿时把它调小，比如 5 万** |
| 随机种子 | 随机数种子。同一个种子 = 同样的效果，方便复现 |
| 游戏版本 | 26.2 或 1.21.11：粒子类型表与贴图按版本切换 |
| 渲染模式 | 完整（真实贴图，推荐）/ 快速（纯色圆点，省资源） |
| 参照物 | 完整模式下显示一个尺寸参照道具：史蒂夫（玩家）/ 命令方块 / 橡树 / 袭击哨塔，帮你比对粒子与方块、实体的相对大小（默认无）。全部使用原版贴图与模型形状；哨塔为原版结构（掠夺者前哨站）1:1 方块布局 |
| 3D 网格 | 显示网格线，帮你对齐坐标 |
| 原版运动学 | 粒子按原版摩擦/重力/随机寿命运动（默认开）。关掉后粒子匀速直线飞 |

## 七、模板库

左侧「📚 模板库」：精选特效（涟漪波面、圆周环），搜索框可过滤（名称/标签/说明）。
每张卡片：
- **📋 复制命令**：把命令复制到剪贴板（含引号等格式，可直接粘进游戏）
- **载入并执行**：清空当前命令与粒子，换成这个模板并立即播放

## 八、分享链接

在网页地址后面加参数即可：
- `?s=<链接>`：打开一个完整场景（命令 + 设置都还原），适合把效果分享
  给别人
- `?t=<模板id>`：直接打开某个模板

链接无效时会提示「分享链接无效或已损坏」，不影响页面正常使用。

## 九、常见问题

**Q：网页很卡怎么办？**
按顺序试：① 设置里把「渲染模式」切成快速模式；② 调小「粒子上限」
（5 万以内绝大多数设备流畅）；③ 关掉「3D 网格」；④ 用最新版 Chrome /
Edge。

**Q：粒子显示不出来？**
- 等首帧加载完成（启动时有进度条，加载贴图可能要几秒）
- 完整模式打不开 WebGL 时会自动切成快速模式（右下角有提示）
- 还不行就手动切快速模式试试

**Q：预览效果和游戏里一样吗？**
命令解析、表达式求值、粒子寿命与运动全部按模组源码 1:1 复刻，报错文案
都一致；个别类型的贴图/发光是视觉近似（差异清单见[技术路线](技术路线.md)）。

**Q：支持什么版本？**
预览支持游戏版本 26.2 / 1.21.11 切换（设置面板）；模组命令语义覆盖
模组支持的全部版本（1.21.1–26.2）。

**Q：报错了？**
看输入框下方的格式检查提示（红字 ⚠️），它会指出「这条命令粘回游戏会
失败」的原因（缺引号、括号不配对、参数超范围等）。修正后重新播放即可。
