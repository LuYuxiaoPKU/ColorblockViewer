# 00 · 模组总览

## 这是什么

ColorBlock（MCBBS 原版）是一个为 Minecraft 增加粒子命令的模组：
用一条（或一组）命令在指定位置生成大量自定义粒子，并支持**用表达式
随时间控制粒子的位置、速度、颜色**——做出涟漪、圆环、波形、拖尾等
复杂特效，不需要资源包、不需要模型。

它新增的命令统一以 `/particleex` 开头；同时保留原版 `/particle` 的
全部能力（预览工具也可解析原版命令）。

## 历史与命名（重要口径）

| 名称 | 指代 | 说明 |
|---|---|---|
| **ColorBlock** | 原版模组 | MCBBS 发布，CC0 开源协议；原帖已随站点数据丢失 |
| **AnotherColorBlock** | 社区版 | 内部名 ParticleEx，社区维护的延续版本 |
| **ColorblockViewer** | 预览工具 | 独立浏览器工具（非模组），把命令粘贴进去即可预览效果 |
| **ExParticle** | 无关工具 | 早期同类工具，与上述模组同名混淆风险，Wiki 引用时注意区分 |

## 版本支持

- **命令树与表达式引擎**：1.21.1 – 26.2 各分支无差异（1:1 移植，跨版本
  语义一致已验证）
- **粒子类型表 / 贴图**：按 1.21.11 与 26.2 分区（旧版本类型少，26.2
  新增 geyser 间歇泉系、firefly 萤火虫、trail 轨迹等）

## 预览工具（强烈推荐配合使用）

https://luyuxiaopku.github.io/ColorblockViewer/

- 粘贴命令 → 立刻看效果 → 满意后复制回游戏，命令文本一字不改
- 引擎与模组 1:1 复刻：报错文案、表达式求值、粒子寿命与运动全部一致
- 内置模板（涟漪波面 / 圆周环，清单见 [07-templates](07-templates.md)）演示模组招牌写法
- 设置面板可切快速模式（纯色圆点）跑大场景

## 能力边界（Wiki 读者须知）

预览引擎已实现：全部 17 个模组子命令 + 原版 /particle 解析；表达式引擎
（含矩阵、条件、随机）；`type{NBT}` 选项（8 类粒子选项）；26.2 运动学
覆盖 100+ 类型（摩擦/重力/寿命与游戏逐字节码一致）。

**不实现**：force/viewers 尾参（原版命令，预览明确报错）；世界依赖的
粒子行为（碰撞、方块检查、流体随机——预览没有世界，见 04-particles）；
纯渲染的贴图发光效果按列表近似（差异清单见预览项目 docs/技术路线.md）。
