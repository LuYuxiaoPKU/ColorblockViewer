# 06 · 常见问题

## 命令/语法

**Q：粒子不出来？**
① 检查位置高度——预览场景看原点附近（y=0 地面），游戏常用高度（y=64/100）
在视野之外，把 y 放 0–4；② 检查粒子上限（默认 100 万，命令生成的粒子
总数超过会丢弃）；③ 看输入框下方格式检查提示（引号/括号/参数个数）。

**Q：normal 的范围为什么不是方块？**
`normal` 的「范围」是高斯分布标准差（源码 `nextGaussian()×range`），
不是均匀立方体——粒子集中在中心、边缘稀疏且无界。规则方块/网格用
`conditional`（见 05-examples）。

**Q：表达式里的引号？**
含括号/逗号的表达式在游戏里必须用引号包住（`'...'`）；预览会自动补，
复制回游戏可直接用。

**Q：RGB 颜色怎么写？**
0–1 小数（如红色 `1 0 0 1`），不是 0–255。经典首错点（社区教程确认）。

**Q：`particleex image ...` 用不了？**
`image`（图片打印）在 ≤1.16.5 老版本存在（图放 mod 同级 `particleImages/`，
flip 取 not/horizontally/vertically）；新版本命令树字段序确认中——
如果预览报「未知子命令」，说明该版本已移除/改名（Wiki 确认后更新）。

## 预览工具

**Q：网页卡顿？**
按顺序：① 设置 → 渲染模式切「快速」（纯色圆点省资源）；② 粒子上限调小
（5 万以内多数设备流畅）；③ 关 3D 网格；④ 大场景自动有提示。

**Q：预览效果和游戏一样吗？**
命令解析、表达式求值、寿命与运动全部 1:1；部分贴图/发光是视觉近似
（差异清单见技术路线 §7）；世界依赖的 8 个粒子类型回退匀速直线。

**Q：粒子寿命无限时能回看多久？**
播放循环不设上限；但**可拖拽回看的历史窗口**受 400MB 内存预算约束：
125 粒子 ≈ 6.7 分钟、4913 粒子 ≈ 10 秒、1M 粒子 ≈ 1.25 秒（各场景
滑动窗口，丢最旧帧；1 tick = 0.05s）。

**Q：1.21.11 版的支持程度？**
类型表/贴图按版本分区；运动学行为两版本共享同一张表（115 型逐类型核对
与 26.2 一致）。老版本粒子类型少（没有 26.2 新增的 geyser/firefly 等）。

**Q：报错文案和游戏一致吗？**
一致。预览的报错/回显解析器与模组命令树逐字核对（1161 个测试锁定），
写错会得到和游戏里一样的提示再去改。

## 生态

**Q：还有别的工具吗？**
社区生态：Particlex Viewer（viewer.dbi.top，网页预览，须 Edge/Chrome）、
HTML 命令生成器（支持 1.12.2/1.16.5 模式、预设、一键复制）；本 Wiki
对应的预览工具 = ColorblockViewer（GitHub 开源）。

**Q：网易版（中国版）粒子指令？**
网易版对原版命令有改动（粒子名/权限），语法差异本节标注「网易版专属」，
与 Java 国际版口径分开（学习来源：B 站 BV12g411g7Tn 等）。
