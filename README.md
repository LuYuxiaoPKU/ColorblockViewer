## 这是做什么的

调 Minecraft 粒子效果有个老痛点：命令参数多、表达式复杂，改一次就要
回游戏里跑一遍看效果——「改一行 → 回游戏 → 跑一遍 → 截图 → 再改」，
来回切换非常低效。

**ColorBlockViewer 把粒子模拟搬进了浏览器**：粘贴命令，页面里立即 3D
渲染粒子的生成、运动与逐 tick 动画；播放、暂停、拖进度条回看、逐帧、
倍速、重置全都有。在预览里确认过的行为，进游戏就是同样的行为——
包括报错提示都逐字一致。

## 快速上手（30 秒）

1. 打开[在线体验](https://luyuxiaopku.github.io/ColorblockViewer/)（或 `git clone` 后本地跑，见文末）
2. **不想写命令**：点左侧「📚 模板库」，精选特效（涟漪波面/圆周环）选一个，点「载入并执行」直接看效果
3. **想自己试**：在左侧粘贴一行命令，点「▶ 播放」
4. 满意了？把命令文本复制回游戏执行（预览里的回显已自动整理成游戏内合法格式）

## 能预览什么

### ① 模组粒子：`/particleex`（ColorBlock 模组）

支持模组的全部 13 个子命令：固定生成 `normal`、条件触发 `conditional`、
位置随表达式变化（`parameter` 系列 4 种）、颜色随表达式变化
（`rgba…parameter` 系列 4 种）、粒子分组批量操作（`group remove/change`）、
清空（`clearparticle`）。

表达式就是数学公式：支持乘除/取余/矩阵/函数/局部变量，写法和游戏内
完全一致。例如水平环形火焰（位置随时间沿圆周运动）：

```
particleex parameter minecraft:flame 0 64 0 1 1 1 1 0 0 0 0 6.2832 'x,y,z=4*cos(t),3*sin(t),0' 0.1
```

支持 MC **1.21.1–26.2** 全部版本（各版本命令与表达式语义一致）。

> 注：本工具以原版 **ColorBlock** 模组（MCBBS 已失效，原帖存档
> [archives.mcbbs.co tid=917845](https://archives.mcbbs.co/read.php?tid=917845)）
> 为移植基准；社区维护版 AnotherColorBlock（内部名 ParticleEx）为原版
> 重写版，命令语义一致，不影响使用。

### ② 原版粒子：`/particle`

支持所选 MC 版本的**全部注册粒子类型**（1.21.11 → 116 种、26.2 → 126 种），
含 `type{NBT}` 复杂写法（如 dust 的自定义颜色/大小）。粒子类型表、贴图、
运动行为按版本分区，与游戏客户端提取数据一致。`delta`/`speed` 按原版
高斯分布语义、`count=0` 单粒子精确生成等细节均逐一复刻。

## 功能一览

- **播放控制**：▶⏸ 播放暂停 / 上一帧下一帧 / 进度条拖拽回看 / 重置 /
  0.125×–8× 倍速；粒子寿命全部结束时自动停止并停在最后一帧，可继续
  拖动回看历史；停在末帧再点播放 = 从头重跑
- **粘贴即跑**：每行一条命令，执行后自动回写成游戏内合法格式
  （表达式缺引号会自动补 `'…'`）
- **游戏内格式检查**：实时标出「这话粘贴进游戏会失败」的问题行
  （缺引号、括号不配对等），不用进游戏才发现
- **模板库**：精选特效（涟漪波面、圆周环），一键载入/复制
- **设置面板**：玩家位置、默认寿命、粒子上限（默认 100 万）、随机种子、
  游戏版本（26.2 / 1.21.11）、渲染模式、3D 网格、原版运动学开关
- **官方贴图**：粒子使用 MC 官方客户端提取的真实贴图，多帧动画按原版
  播放顺序推进 + 后半程淡出
- **场景链接**：`?s=<链接>` 打开后还原整个场景（命令+设置），分享给
  别人直接看到你的效果；`?t=<模板id>` 直达模板
- **首帧预热**：启动时后台加载贴图与着色器，带进度条，不白屏

## 两种渲染模式

| | 完整模式（默认，推荐） | 快速模式 |
|---|---|---|
| 画面 | 官方贴图 + 帧动画 | 纯色圆点（软发光） |
| 速度 | 更好 | 更省资源，低配设备更流畅 |
| 什么时候用 | 平时预览 | 电脑配置低 / 大场景卡顿 / 网页很卡时 |

网页打不开 WebGL（无显卡/被禁用）时**自动切换快速模式**，仿真照常跑。
粒子很多（≥20 万）且用完整模式时，页面会提示你换快速模式。

## 常见问题

**和游戏里真的完全一样吗？**
是的。命令解析、表达式求值、粒子寿命与运动按模组 Java 源码逐字移植，
报错文案都逐字一致；渲染层（贴图/发光）尽力还原，个别类型有微小视觉
近似（详见[技术路线](docs/技术路线.md)的已知简化清单）。

**网页很卡怎么办？**
① 设置里切「快速模式」；② 调小「粒子上限」（10 万以内一般设备都流畅）；
③ 关掉「3D 网格」；④ 用 Chrome/Edge 最新版。

**支持哪些游戏版本？**
预览侧支持 MC 26.2 / 1.21.11 双版本切换（在设置面板），粒子类型表与
贴图按版本区分。模组命令语义覆盖模组支持的 1.21.1–26.2 全部版本。

**粒子显示不出来/一片黑？**
完整模式打不开 WebGL 时会自动降级快速模式（右下角有提示）；如果画面
空白，刷新页面，或手动切到快速模式排查。
